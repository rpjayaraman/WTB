# ⚡ What The Bug — Verification Battle Station

> A free, open learning platform for VLSI verification engineers — students & freshers welcome!

🌐 **Live at**: [whathebug.com](https://whathebug.com)

## What's Inside

| Module | Description |
|--------|-------------|
| 🏠 Dashboard | 30-day learning roadmap tracker |
| 📘 SV Coding | SystemVerilog coding challenges |
| 🧪 SVA/Coverage | Assertions & functional coverage exercises |
| 🌊 Waveform Sandbox | Interactive waveform viewer |
| 📚 LRM Deep Dive | Language Reference Manual exercises |
| 🗄 Dataset Manager | Manage your learning datasets |

## Tech Stack

- **Frontend**: Pure HTML5 + CSS3 + Vanilla JS (no frameworks)
- **Hosting**: GitHub Pages (free)
- **Domain**: `whathebug.com` via GoDaddy
